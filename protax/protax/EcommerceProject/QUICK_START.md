# 🚀 Quick Start Guide

## Start the Application

```powershell
cd c:\Users\harsh\OneDrive\Desktop\protax\EcommerceProject
mvn jetty:run
```

**Wait for**: "Started Server" message (takes 10-30 seconds)

## Access the Application

**Base URL**: http://localhost:8081

### Quick Links:
- 🏠 **Home**: http://localhost:8081/
- 🛍️ **Products**: http://localhost:8081/ProductServlet
- 🔐 **Login**: http://localhost:8081/login.jsp
- ✅ **Test DB**: http://localhost:8081/db-test
- 👤 **Admin**: http://localhost:8081/admin/dashboard.jsp
